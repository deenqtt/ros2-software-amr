## Detail Fitur per Panel

### Mission Panel
```
Destinations → tambah titik di peta (Pick / Drop / P&D)
Waypoints    → maks 5 titik, pilih dari destinations
Options      → Loop (count 0=∞), Timeout per waypoint (default 120s)
Controls     → Start / Pause / Stop
Manual mode  → tombol "Confirm" muncul saat robot menunggu konfirmasi
```

**Alur eksekusi mission:**
```
Start
 └─ followWaypoints(waypoints[])
      └─ _sendMissionGoal(index=0)
           └─ send_action_goal → /mission_plan
                ├─ feedback: NAVIGATING → ARRIVING → EXECUTING_PICK/DROP
                ├─ [jika Manual] → WAITING_CONFIRM → tunggu tombol Confirm
                └─ result: SUCCESS
                     └─ _advanceMission() → index++
                          ├─ [ada waypoint berikutnya] → _sendMissionGoal(index+1)
                          └─ [selesai semua]
                               ├─ [loop aktif] → followWaypoints() lagi
                               └─ [selesai] → stopMission()
```

**ROS interface mission:**
| Arah | Interface | Keterangan |
|---|---|---|
| UI → Robot | `send_action_goal /mission_plan` | Kirim satu waypoint per goal |
| Robot → UI | `/mission_plan/_action/status` | Deteksi goal selesai |
| Robot → UI | `/mission_plan/_action/feedback` | Status teks navigasi |
| UI → Robot | `service /mission_confirm` | Konfirmasi Manual mode |
| UI → Robot | `service /mission_plan/_action/cancel_goal` | Cancel goal aktif |

---

### Navigation Panel
- Single point navigate → klik peta / input koordinat → `/goal_pose` topic
- Set initial pose AMCL → klik + drag di peta → `/initialpose`
- Cancel navigation → service `/navigate_to_pose/_action/cancel_goal`

### Docking Panel
- Daftar dock stations dari backend API
- Send to dock → service `/dock_command` `{ action: "dock", station_id, station_name }`
- Undock / Cancel
- Status realtime dari topic `/dock_status`
- Auto-dock jika baterai rendah (configurable threshold)

### Mapping Panel
- Toggle SLAM / Nav mode
- Save map → service `/map_saver/save_map`
- Joystick teleop → publish `/cmd_vel` tiap 80ms

### Setup Panel
- Map manager: upload `.yaml` + `.pgm`, activate map
- Destination editor: CRUD, rename, ubah type
- Dock station editor: set posisi + approach point

### Status Bar
- Koneksi ROS (connected/disconnected)
- Robot pose (x, y, θ)
- Battery percent + charging indicator
- Nav status (idle/navigating/executing/waiting_confirm/docking)
- Map save button

## Custom Interfaces (ROS2)

```
custom_interfaces/action/MissionPlan.action
  Goal:
    geometry_msgs/PoseStamped dest_pose
    int8 dest_tasks          # 1=Pick, 2=Drop
    bool continue_mode       # true=Auto, false=Manual
  Result:
    string result            # SUCCESS / FAILED:<reason> / CANCELED
  Feedback:
    string mission_sts       # NAVIGATING(Xm) / ARRIVING(Xm) /
                             # EXECUTING_PICK / EXECUTING_DROP /
                             # WAITING_CONFIRM / SUCCESS

custom_interfaces/srv/DockCommand.srv
  string action              # dock / undock / cancel
  uint8 station_id
  string station_name
  ---
  string result

custom_interfaces/srv/StationConfig.srv
  uint8 id
  string name
  uint8 type                 # 0=Pick, 1=Drop, 2=Pick&Drop
  uint8 action               # 0=delete, 1=save
  float64 x_pose, y_pose, yaw_pose
  float64 x_approach, y_approach, yaw_approach
  ---
  string result
```

## Known Issues & Catatan

| # | Issue | Status | Catatan |
|---|---|---|---|
| 1 | `missionProgress` bar hitung kurang tepat | Open | `index/total` → seharusnya `(index+1)/total` |
| 2 | roslibjs tidak emit `action_result`/`action_feedback` | Workaround | Pakai subscribe `_action/status` topic sebagai gantinya |
| 3 | Manual mode belum ada timeout | Open | Robot bisa stuck selamanya jika operator lupa confirm |
| 4 | `MissionEditor.vue` duplikat logic dengan `MissionPanel.vue` | Open | Perlu cleanup, gunakan salah satu |
| 5 | Keepout zones tidak persist di ROS setelah rosbridge restart | Workaround | Re-publish dari localStorage saat reconnect (sudah diimplementasi) |
